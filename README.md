# SkillHub

Learn a Skill. Build Your Future.

SkillHub is a digital learning platform for practical skills — built to grow from a focused MVP into a skills-to-opportunity platform.

## Version 1 (MVP)

Home → Courses → Virtual Assistance → Signup/Login → Learning → Quiz → Progress

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Zustand (local auth + progress)
- React Hook Form + Zod
- Lucide React

See `FOUNDATION.md` for product rules, design tokens, and roadmap.
